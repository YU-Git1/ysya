# QuackPress（压缩鸭）品牌定位

## 命名

- 中文名：压缩鸭
- 英文名：QuackPress
- 品类描述：图片压缩与格式转换工具
- 品牌个性：可爱、可靠、轻快、讲人话
- 一句话：图片变轻，网页更快。

## TinyPNG 值得学习的优势

根据 2026-10-09 对 TinyPNG 公开首页的查看：

- 首页直接以拖放上传为中心，限制和操作一眼可见。
- 支持批量处理，并提供自动转换能力。
- 用原图与结果对比证明“文件变小、观感仍好”，而不是只说算法先进。
- 同一套压缩能力扩展到开发者 API、WordPress 插件和 CDN，形成清晰的产品阶梯。
- FAQ、格式说明、隐私说明和客户案例降低使用疑虑。

## 压缩鸭当前可以建立的优势

- 本地处理：当前 MVP 使用浏览器 Canvas，图片不需要传到压缩鸭服务器。隐私说明应与这一实现保持一致。
- 格式选择直观：保持原格式是默认项，也可以主动转换成 JPG、PNG 或 WebP；结果和下载按钮显示真实输出格式。
- 中文优先：限制、状态、失败原因和操作全部使用直接易懂的中文。
- 轻量工作流：无需注册即可完成上传、预览和下载。
- 亲和品牌：鸭子角色让工具显得轻松，但处理状态、文件信息和隐私说明仍保持清楚可信。

上述优势只描述当前已实现的能力，不承诺优于 TinyPNG 的压缩率或视觉质量。后续应使用公开、可复现的图片样本集，比较各格式的体积和视觉差异，再决定是否提出性能类宣传。

## 后续验证方向

- 维护 JPG、PNG、WebP 的基准样本集，跟踪输出体积和主观画质。
- 用用户任务测试验证“保持原格式”是否容易理解，以及批量下载是否需要 ZIP。
- 观察文件转换失败率、下载成功率和移动端长任务体验。
- 等真实后端、额度和 API 能力交付后，再扩展面向团队和开发者的定位。

## 标识使用

`public/duck-mark.svg` 是压缩鸭的基础图形标识：浅黄绿色方形底、奶油白鸭身、橙色鸭嘴和深色描边。它面向小尺寸导航与 favicon 使用；后续可从同一角色延展状态表情，不改变基础轮廓。
